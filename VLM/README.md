# BridgeVLM

## BridgeVLM: Semi-Supervised Vision–Language Framework for Bridge Defect Component Semantic Anchoring and Standard-Constrained Report Generation

BridgeVLM 是一个面向桥梁病害智能检测与报告生成的视觉语言框架，聚焦于：

- **桥梁病害与构件的语义关联**：将检测到的病害与对应桥梁构件进行语义锚定；
- **半监督学习**：利用有限标注数据与未标注数据，提高桥梁病害识别与理解能力；
- **标准约束报告生成**：依据预设的检测规范、构件信息和病害描述，生成结构化桥梁检测报告；
- **多模态推理**：结合图像、文本提示、构件类别与病害语义信息进行联合分析。

BridgeVLM is a visual language framework for intelligent bridge defect detection and report generation, focusing on:

- **Semantic Association between Bridge Defects and Components:** Semantically anchoring detected defects to corresponding bridge components;

- **Semi-Supervised Learning:** Improving bridge defect identification and understanding capabilities using limited labeled and unlabeled data;

- **Standard-Constrained Report Generation:** Generating structured bridge inspection reports based on preset inspection specifications, component information, and defect descriptions;

- **Multimodal Reasoning:** Jointly analyzing images, text prompts, component categories, and defect semantic information.
